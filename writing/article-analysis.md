# 記事分析: 「7STEP」note記事はなぜ売れる構造なのか

後藤さん(@goto_thex)の記事を、構成・心理設計の観点から分解したメモ。

## 1. 記事自体が「生きたデモ」になっている(メタ構造)

冒頭で「1000部売れたnoteも、反響のあった記事も、この7STEPで作った」と宣言し、
さらに「この記事自体も同じ7STEPで作っている」ことをスクショで見せている。

- 手法の解説記事でありながら、記事そのものが手法の実演サンプル
- 「読んでいるこの文章の質」がそのまま手法の証明になるため、反論の余地がない
- 実績スクショ(1000部・読者の反響)を冒頭に置き、読み進める理由を先に作る

## 2. ターゲット選定の逆張り

X上に溢れる「Claude Code・AIエージェント・自動化」系の発信に対して、

- 「いや、もうよう分からんくね?」と読者の疲労感を代弁
- 「今回そういうの一切使いません」「僕自身AI全然知りません」「脳筋です」と宣言

これにより、AI上級者向け発信では拾えない
**「ChatGPTだけスマホに入ってる層」**という巨大なボリューム層を独占的に取りにいっている。
弱者側に立つポジショニングで親近感も同時に獲得。

## 3. 離脱ポイントの先回り潰し

読者が離脱しそうな瞬間を、すべて先回りで処理している。

| 読者の心の声 | 記事側の返し |
|---|---|
| 「7STEP覚えるのダルい」 | 最後にコピペ用プロンプトを用意 |
| 「意外と普通やん」 | 「その通りです。差がつくのは何をAIに任せて何を自分で握るか」 |
| 「毎回これ全部やるのダルい」 | 「その通りです。だからプロンプトを置いておきます」 |
| 「本当に再現できるの?」 | 実際のChatGPT履歴のスクショを随所に提示 |

反論を先に言われた読者は反発できず、読み続けるしかなくなる。

## 4. 保存インセンティブの設計

「一回読んで終わる読み物ではなく、次に長文を書く時のマニュアルとして使ってください」
「今すぐ書く予定がない人も、この記事だけ保存しておいてください」

- 保存 → 再訪 → プロフィール・CTA再接触、という導線を明示的に作っている
- noteやXのアルゴリズム上も保存・ブックマークはエンゲージメント評価に効く

## 5. 独自ワードと文体によるキャラ立ち

「ボコボコにする」「これあかんやろ」「脳筋」「あざす」「ウーロンハイ飲みながら読みます」など、
綺麗なビジネス文体を意図的に崩した言葉選び。

- 記事内で教えている「独自ワード」「本人の言葉を残す」をそのまま実践
- AI文章っぽさの排除 = 記事の主張(AIだらけのXで差別化)の体現

## 6. 最後の「どんでん返しCTA」

約1万文字かけて7STEPを解説し、保存推奨までした上で、

> 「月100万円なら今までの話、全部忘れてOKです」

と記事全体を自分でひっくり返す。

- 疲れた読者の注意を最後に再喚起する強烈なパターン破り
- 「文章力より先に売れる仕組み」という新しい問題提起で、リードマグネット
  (0フォロワーから55日で119万円のスキーム)への欲求を最大化してから受け渡す
- これは記事内STEP⑦で本人が語っていた「どんでん返し感を出したい」の実践そのもの

## 7. CTA構造は自作プロンプトの教科書通り

AI編集長プロンプト内のCTA基本構造:

> 問題を理解 → 原因を理解 → 解決策を理解 → 一人では難しい理由 → 次の行動

記事全体がこの流れになっている。

1. 問題: AI文章だらけのXで埋もれる
2. 原因: 一次情報(原料)までAIに作らせているから
3. 解決策: 7STEP(何を任せ、何を握るか)
4. 一人では難しい: 「全部やるのダルい」→ プロンプト提供で解消
5. 次の行動: 保存・いいね・フォロー・引用 + リードマグネット受け取り

## 8. 返報性の設計

プロンプト2本(合計でそれ自体が商品級のボリューム)を無料で全部公開。

- 「ここまで無料でくれるなら」という返報性が、いいね・フォロー・引用感想・
  リードマグネット受け取りの心理的ハードルを大きく下げる
- 「有益すぎて消してくれ」という読者の声の引用も、価値の社会的証明として機能

## まとめ: この記事の再現可能な型

1. 冒頭に実績+この記事自体が実演サンプルであるというメタ宣言
2. 飽和した競合の逆を張るポジショニング宣言で読者を絞る
3. 離脱しそうな心の声を先回りで代弁して潰す
4. 保存させる理由(マニュアル化・コピペ資産)を明示する
5. 独自ワードでAIっぽさを消し、キャラを立てる
6. 最後に自分の記事をひっくり返して、本命CTAへ繋ぐ
